# Cinemax — Project Showcase Assets

## Mục đích

Thư mục này chứa **ảnh chụp thực tế của dự án Cinemax** do chủ dự án cung cấp. Đây là source ảnh ưu tiên để Codex sử dụng khi cập nhật trang portfolio/project trên MTWebsite.

## Quy tắc cho Codex

- Đọc file này trước khi chỉnh phần project Cinemax.
- Sử dụng **các screenshot thật trong thư mục này** cho gallery/carousel/project detail.
- Không thay các screenshot này bằng placeholder, mockup ngẫu nhiên hoặc ảnh stock.
- Có thể crop/resize bằng CSS để đồng bộ giao diện, nhưng không làm sai nội dung ảnh.
- Giữ ảnh gốc trong thư mục; nếu cần ảnh tối ưu cho production, tạo bản copy ở thư mục public phù hợp.
- Không sửa chức năng của Cinemax từ các screenshot; đây là tài liệu hình ảnh để giới thiệu dự án.
- Khi chọn ảnh cover, ưu tiên `09-home-hero-1.png`, `11-home-hero-2.png` hoặc `12-movie-detail.png`.
- Gallery nên thể hiện cả giao diện người dùng và trang quản trị.
